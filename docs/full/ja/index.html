まるごと圧縮。

project.json の論理圧縮と、コスチューム・音のメディア圧縮を まとめて実行し、最後に1回だけ梱包し直します。すべてこのタブ内で完結し、 アップロードもインストールも要りません。

各 SVG コスチュームに、圧縮日時（UTC）・元のファイル名・バージョン・オプションを含む小さな SB3 Tools 透かしが入ります。透かしチェッカーで確認できます。
