壊れた Scratch / TurboWarp プロジェクト向け

壊れた場所を探し、
元に戻す。

.sb3 を読み込み、Scratch / TurboWarp のプロジェクト構造に 照らして厳格に検証します。壊れた ZIP や project.json の復元、 ブロック参照・変数・アセット・カスタムブロック・モニターの修復を行い、 読み込める .sb3 を書き出します。アップロードはありません。

厳格な検証。 エラーと警告を分けて表示し、修復後はダウンロード前に再検証します。 見つからないメディアは透明なコスチューム／無音の音に置き換えます。 途中で切れた project.json の失われた末尾は復元できません。

.sb3 / project.json
