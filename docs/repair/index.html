For damaged Scratch and TurboWarp project files

Find what broke.
Put it back.

Reads an .sb3, validates it against the Scratch / TurboWarp project structure, recovers a damaged ZIP or project.json, repairs dangling block links, missing stores, assets, custom-block mutations and monitors, then writes a loadable .sb3. Nothing is uploaded.

Strict by design. The checker reports errors separately from warnings. A repaired file is re-validated before it is offered for download. Missing media is replaced with a transparent costume or a silent sound; data cut off the end of a truncated project.json cannot be recreated.
