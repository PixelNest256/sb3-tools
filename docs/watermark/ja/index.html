SB3 Tools で作った .sb3 向け

透かしを読み、
設定を復元する。

すべての SVG コスチュームから SB3 Tools の透かしを見つけ、圧縮日時（UTC）、 圧縮前のプロジェクト名、ツールのバージョン、使用したオプションを読み取ります。 ローカルの .sb3 を開くか、公開 Scratch プロジェクトの ID を 入力して取得できます。手元のファイルはアップロードされません。

保存方法。 透かしは各 SVG コスチューム内の、表示されない <desc> 要素です。幾何情報を持たないため Scratch / TurboWarp には描画されず、 Scratch の SVG サニタイザーや通常のプロジェクト保存でも残ります。 アセットの MD5 もバイト列と一致したままです。独自の強い最適化設定で SVG 自体を書き換えるツールでは消えることがあります。
