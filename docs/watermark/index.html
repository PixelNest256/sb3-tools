For .sb3 files made by SB3 Tools

Read the mark.
Recover the settings.

Finds the SB3 Tools watermark in every SVG costume and reads back the UTC compression time, the original project name, the tool version and the exact option flags used by the compressor. Open a local .sb3, or enter a public Scratch project ID to fetch and check it. Nothing from your computer is uploaded.

How it is stored. The watermark is an invisible <desc> element in each SVG costume. It has no geometry, so Scratch and TurboWarp never draw it, and it survives Scratch's SVG sanitizer and normal project saves. The asset's MD5 stays consistent with its bytes. A tool that rewrites the SVG with an aggressive custom optimiser may still remove it.
