.sb3 を圧縮

使っていないデータを削り、ID を短くし、繰り返すコードをひとつに まとめます。書き出した .sb3 は、これまでと同じ動作の まま開けます。アップロードもインストールも要りません。

読み込み
.sb3 / project.json
書き出し
*_compressed.sb3

入力

.sb3 / .json
.sb3

プロジェクトをドロップ

または ファイルを選択

project.sb3 —
